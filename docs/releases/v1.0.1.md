**Lionstone v1.0.1 is a maintenance release of [v1.0.0](https://github.com/ismailarslantas/lionstone/releases/tag/v1.0.0): one render fix, continuous fuzzing and stricter supply-chain checks. Everything in v1.0.0 (25 Motion FX, Lionstone Editing, Reels, Styles, Pro & Studio) is unchanged. Free and open source, Apache-2.0.**

## Fixed

- **Audio and video stay in sync when the video is longer than the audio.** Some recordings (phone videos, files with an encoder flush at the end) have a video track that outlasts the sound. Lionstone now never runs a segment past the end of the source audio, so the finished video and its audio have the same length and the QA check `av_length` passes.

## Security and quality

- **Fuzzing**: an Atheris fuzzer for the parsers that read user text (timecodes, chapters, speakers, filler words) runs in ClusterFuzzLite on every pull request that touches the code, and Hypothesis property tests run with the unit tests.
- **Pinned CI dependencies**: CI and the release workflow install exact, hash-checked versions; Dependabot keeps them current.
- CI jobs have time limits and retrying package downloads.
- Remotion 4.0.541 (Dependabot).

## Install

```bash
pip install "lionstone[all] @ git+https://github.com/ismailarslantas/lionstone@v1.0.1"
lionstone doctor
```

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify lionstone-1.0.1-py3-none-any.whl --repo ismailarslantas/lionstone
```
