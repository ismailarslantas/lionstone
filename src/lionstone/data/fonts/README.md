# Bundled fonts

Used by the Lionstone Reels looks so they render the same on every system. Unmodified, each under the
SIL Open Font License 1.1, which allows bundling with software, including commercial use. The fonts
are not sold on their own. Videos made with them carry no licence obligation.

| Font | Files | Licence |
|---|---|---|
| Poppins | Poppins-Medium, Poppins-Bold, Poppins-BoldItalic | OFL-Poppins.txt |
| DM Serif Display | DMSerifDisplay-Italic | OFL-DMSerifDisplay.txt |

Source: github.com/google/fonts. To remove them, delete this folder: the looks using them are the
Editorial and Glow titles and the `editorial` and `keyword-pop` captions.
